# Clientes 360

Panel analítico de cartera de clientes construido con React, TanStack Router y Tailwind CSS.

## Funcionalidades

- Inicio de sesión de demostración.
- Vista general de clientes en tabla con búsqueda.
- Filtros por segmento, producto, ciudad y categoría de consumo.
- KPIs: ingresos, contratos, satisfacción y clientes en riesgo.
- Sección preparada para embeber un dashboard de Power BI.
- Diseño responsive.

## Desarrollo

```bash
bun install
bun run dev
```
